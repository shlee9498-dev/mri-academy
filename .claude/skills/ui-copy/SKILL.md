# MRI UI 문구 톤

사용자에게 보이는 문장을 **한 줄이라도** 쓰거나 고치면 이 문서가 적용된다. 버튼 한 단어, placeholder, `aria-label` 의 읽히는 부분, 봇 DM, 알림 제목, 랜딩 카피까지 전부. 코드 주석·로그·오류 코드(`slot_taken` 같은 식별자)·개발자 문서는 대상이 아니다.

매일 여는 앱이다. 딱딱하면 안 열게 된다. 우리가 원하는 느낌은 **"실력 좋은 친한 트레이너가 옆에서 말해 주는 것"** 이다.

## 1. 핵심 규칙

1. **"~요"체.** "~습니다"체 금지. 「저장되었습니다」 ✗ → 「저장했어요!」 ✓
2. **밝고 다정하게.** 정보만 던지지 말고 사람에게 말하듯.
3. **느낌표를 아끼지 않는다.** 「괜찮아요!」 「바로 보여요!」 「로그인 성공!」 단, 한 문장에 하나. 연속 「!!」 금지.
4. **이모지는 뜻이 맞는 것만.** 장식이 아니라 문장의 의미를 가리킨다. 문장 끝 또는 제목 앞에 하나. 표는 §4.
5. **불안한 상황은 안심부터.** 첫 문장은 「거의 다 왔어요」 「정상이에요!」 「로그인은 됐어요!」 같은 안심 신호. 설명은 그다음.
6. **단계 안내 = 이모지 + 제목 + 왜 하는지 한 줄.** 「💬 봇이 DM을 보내요 — 본인 확인을 위해서예요」
7. **놓치기 쉬운 지점엔 안심 신호.** 「닉네임이어도 괜찮아요!」 「조금 걸릴 수 있어요」 「짧아도 괜찮아요」
8. **끝은 창구를 열어 둔다.** 「막히면 담당 트레이너에게 편하게 물어보세요」 — 특히 대기·실패·빈 화면.
9. **명령조·시스템 어투 금지.** 「~하십시오」 「~바랍니다」 「오류가 발생했습니다」 「처리 중입니다」 「입력하세요」 ✗
10. **사용자를 탓하지 않는다.** 「잘못 입력했습니다」 ✗ → 「다시 한 번 볼까요?」 ✓. 실패는 "우리가 못 한 것"으로 쓴다. 「예약이 안 됐어요」 ✓ 「예약에 실패하셨습니다」 ✗

## 2. 예외 — 돈·오류·법적 고지는 절제

**손해나 책임이 걸린 문구**는 이모지와 느낌표를 줄인다. 가벼워 보이면 신뢰를 잃는다. 담백하되 여전히 다정하게, "~요"체는 유지.

해당하는 것: 판수 부족·차감·선차감, 결제·환불, 취소 불가·취소 마감, 정원 마감으로 인한 거절, 개인정보 처리방침·약관·동의, 계정 정지, 데이터 삭제.

| | 일반 문구 | 돈·오류·법 문구 |
|---|---|---|
| 느낌표 | 적극적으로 | 사실 문장에는 안 씀. 「취소했어요.」 (뒤에 붙는 좋은 소식엔 가능 「5판이 돌아왔어요!」) |
| 이모지 | 문장당 1개 | 없음 또는 제목에 1개 |
| 길이 | 짧게 | 사실 + 다음에 할 수 있는 일 한 줄 |
| 안심 신호 | 「괜찮아요!」 | 「급한 사정이면 담당 트레이너에게 말해 주세요」처럼 **창구**로 대신 |

## 5. 쓰기 전 체크리스트

- [ ] "~요"로 끝나는가? "~습니다" "~하십시오" "~바랍니다" 가 없는가?
- [ ] 불안한 화면이면 첫 문장이 안심 신호인가?
- [ ] 이모지가 문장의 뜻과 맞는가? (표 §4) 하나뿐인가?
- [ ] 사용자를 탓하는 말("잘못" "실패하셨")이 없는가?
- [ ] 막힌 화면(대기·실패·빈 화면)에 창구(트레이너·DM)가 열려 있는가?
- [ ] 돈·취소·법 문구면 느낌표·이모지를 뺐는가?
- [ ] 숫자·날짜·판수 같은 사실은 그대로 정확한가? (톤을 바꾸며 사실을 바꾸지 않는다)
- [ ] 기존 테스트가 이 문구를 검사하고 있다면 함께 고쳤는가?

## 6. 다른 저장소에 복사하기

이 스킬은 자립적이다 — 특정 앱의 화면 이름이나 코드에 기대지 않는다. mri-academy · gmi-casino-bot · gmi-clancup 등 MRI 저장소 어디든 그대로 복사한다.

```powershell
# PowerShell — 저장소 루트에서
New-Item -ItemType Directory -Force .claude\skills\ui-copy | Out-Null
Copy-Item ..\mri-student-app\.claude\skills\ui-copy\SKILL.md .claude\skills\ui-copy\SKILL.md
```

```bash
# bash
mkdir -p .claude/skills/ui-copy && cp ../mri-student-app/.claude/skills/ui-copy/SKILL.md .claude/skills/ui-copy/
```

복사한 뒤 그 저장소의 `CLAUDE.md` 에 한 줄 추가해 세션 시작 시 인지되게 한다:

```
- 사용자에게 보이는 문구(UI·오류·빈 화면·버튼·알림·봇 응답·웹 카피)를 쓰거나 고칠 때는 `.claude/skills/ui-copy/SKILL.md` 를 따른다.
```

봇 저장소라면 §3 「봇 응답 · DM」 표에 그 봇의 실제 명령 예시를 몇 줄 덧붙여도 된다. 규칙(§1·§2)은 저장소마다 바꾸지 않는다 — MRI 전체가 한 목소리여야 한다.
