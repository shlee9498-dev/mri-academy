> 오너(10/28): 「내 자기장 운빨 현황 내팀운 수준 내가팀에서하는 기여도수준 이런 걸 몇판데이터로 취합해서 당신은 이런 걸 잘하는사람이다 + mbti랑 엮어서 유쾌하게」 ·

> 이번 결과물은 **화면이 아니라 「계산이 되는지」 증명**이다. 운영 DB · 결제 · 정산 · 수강생 데이터는 손대지 않았다.

## 0. 한 줄 결론

- 지표 5개 **전부 공식 리플(텔레메트리)로 계산된다.** 바꾼 정의 2개 · 리플로 안 되는 칸 1개(어시 · 옛 형식)는 §2.
- 비교 기준은 **언제나 「같은 판 로비」**다(로비 평균 · 로비 안 순위). 서버 전체 · 동접 · 플레이어 수 추정은 하지 않는다(약관 · 키 회수 사유).
- ⚠ **무리 계정(GmI_mriacademy) 실데이터 카드는 아직 못 만들었다.** 이 컨테이너는 `api.pubg.com` · 텔레메트리 CDN · 운영 서버가 전부 막혀 있다(프록시 403 · 10/28 다시 확인).
  대신 ① 공개 리플(2019 · 98명 한 판 전체)로 엔진을 증명하고 ② 운영 서버에 **운영진만 부를 수 있는 시험 주소**를 붙였다 —
  머지 · 배포 뒤 운영진 로그인 브라우저에서 `/api/replay/saju?name=GmI_mriacademy&platform=steam&n=20` 한 번이면 무리 계정 카드 + 판별 근거표가 나온다(§6).

| ② 팀운 | 팀원(나 제외)의 딜 · 생존 시간 = 로비 평균의 몇 배 · 기절당함 = 로비 평균 ÷ 팀원 평균(적게 기절할수록 좋게). 셋 평균 1.15배↑ 좋음 · 0.85배↓ 나쁨 | 됨 | 딜 · 기절 = 사람 피해만(자기장 · 출혈 · 팀킬 · 자해 제외) |

| ⑤ 한 줄 해설 | 4축 중 가장 뚜렷한 축 → 「당신은 ○○를 잘하는 사람」 + 근거 숫자 하나 · 잘 맞는 듀오 = 공격/인내 · 원거리/근거리는 반대(빈칸 채움) · 중심/외곽 · 팀플/독고는 같게(동선 맞음) | 됨 | 재미 위주 규칙. 문장은 문구 표 그대로 |

- 판이 적거나 일찍 죽어서 축이 비면 유형 대신 「판이 조금 더 쌓이면 유형이 나와요」. 공개 표본 한 판에서는 98명 중 27명만 4축이 다 나왔다(나머지는 2페이즈 전에 죽음 · 딜 3번 미만). 20판이면 거의 다 채워진다(예상).
- **동접 · 플레이어 수 추정 없음**: 로비 비교는 그 판 텔레메트리 안 사람들끼리만. 판 수 · 인원 합계를 어디에도 쌓지 않는다.

## 4. 처리 시간 · API 호출 · 한도 계산

**한 판 처리(이 컨테이너 실측 · 공개 경기 98명)**: 텔레메트리 원본 20.2MB(gzip 1.7MB) · JSON 읽기 140~420ms · 모든 플레이어 요약 80~140ms · 요약 크기 29KB.
다운로드 시간은 이 컨테이너가 PUBG CDN 에 못 닿아 **미측정** — gzip 1.7~3MB 기준 0.3~1초로 잡으면 **한 판 약 1초 · 20판 약 20초 · 10판 약 10초**(첫 조회 · 캐시 없을 때).

**API 호출(한 사람 · n판)**

| 호출 | 횟수 | 한도 |
|---|---|---|
| 닉네임 → 계정 + 최근 경기 목록(`/players`) | 1 | **분당 10회 한도에 든다** |
| 경기 객체(`/matches/{id}`) | n | 한도 밖(공식 문서) |
| 텔레메트리(CDN) | n(같은 판은 캐시) | 한도 밖 · 키 필요 없음 |

**동시 사용자 계산**
- 지금 구조(키 1개를 전적 · 킬내기와 나눔 · 복기 몫 분당 4회): **새 닉네임 분당 4명**(시간당 240명). 같은 닉 90초 안 재조회는 0회.
- 키 하나를 이 앱이 다 쓰면 분당 10명. `/players` 는 한 번에 닉 **10개까지** 묶어 물을 수 있어서, 1~2초 모아 묶으면 **분당 최대 100명**까지 한도 안.
- **진짜 병목은 한도가 아니라 텔레메트리 처리**다: 한 칸(동시 1판) 기준 판당 약 1초 → 20판이면 1명에 20초 → **분당 약 3명(첫 조회)**. 같은 로비 사람 · 다시 온 사람은 요약 캐시(400판 · 약 12MB)로 0초.
  → 손님이 몰리면 ① 기본 판 수를 10판으로 ② 처리 칸을 늘리거나 별도 작업 서버 ③ 판 요약을 저장(§7)해서 재사용.

## 5. 지켜야 할 것 — 확인

- API 기반 기능은 **전부 무료** · 로그인 없이 닉네임만(공개판). 지금 시험 주소는 운영진만(공개 결정 전 뒷문 방지 · #589 검수 원칙 그대로).

- 이름에 상표 없음: 성격유형 검사 이름 · 게임 정식 명칭 · 줄임말을 문구 표 화면 글자에 안 쓴다(시험이 확인). 그래서 작업 제목은 **「자기장 사주」(가칭)** — ⚠ 「배그 사주」의 「배그」도 게임 이름 줄임말이라 공개 이름으로는 피하길 권한다(오너 결정 1).
- 다국어: 카드 글자는 전부 `saju-strings.json`. 구조는 §9.

## 9. 언어 — 한 앱에서 고른다(10/28 총무 추가 조건 · 오너 「만국공용으로 앱내에서 자체선택」)

- **나라별 앱을 따로 만들지 않는다.** 화면 · 카드 · 공유 이미지가 전부 `saju-strings.json` 한 표에서 글자를 꺼내고, 언어는 코드 한 개(`lang`)로 바뀐다.
- **처음 열 때**: 브라우저 언어 목록(`navigator.languages`, 서버는 `Accept-Language`)에서 처음 맞는 언어 → 없으면 영어(`pickLang`).
  `ja-JP → ja` · `pt / pt-PT → pt-BR` · `zh-CN / zh-SG → zh-Hans` · 번체(`zh-TW · zh-HK`)는 칸이 없어 다음 언어로.
- **바꿀 때**: 오른쪽 위 언어 칩 하나 → 목록(그 나라 글자로 적은 이름 `_langs.native` · 순서도 `_langs`). 고른 언어는 브라우저에만 기억(`localStorage`) · 주소에도 `?lang=th` 로 실어서 공유 링크를 연 친구도 같은 언어로 본다(친구가 칩으로 바꾸면 그쪽 우선).
- **빈 칸**: 그 언어에 없는 문장은 영어로(→ 영어도 없으면 한국어). 그래서 포르투갈어 · 중국어 간체 · 러시아어 · 베트남어는 칸만 만들어 두고 비워 놔도 화면이 깨지지 않는다(시험이 확인).
- **공유 카드 이미지**도 고른 언어 그대로(`cardSvg` · 1080×1350). 태국어는 띄어쓰기가 없어서 줄바꿈을 단어 단위(`Intl.Segmenter`)로 끊는다. 글꼴: 한국어 Pretendard · 일본어 Noto Sans JP · 태국어 Noto Sans Thai · 중국어 Noto Sans SC(공개 화면에서 같이 불러온다). PNG 는 브라우저가 canvas 로 바꿔 저장 · 공유한다(서버 부담 없음).
  운영진 확인용: 시험 주소에 `&lang=th&format=svg` 를 붙이면 이미지가 그대로 열린다.
