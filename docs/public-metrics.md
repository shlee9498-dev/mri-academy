# 공개 지표 — 최근 30일 실측 (2026-09-30 · 오너 지시)

> 사이트의 누적 · 과거 수치(「30명+」 · 「50명+」 등)를 빼고 **최근 30일 실측을 매일 자동 계산**해 보여 준다.
> 서버: `public-metrics.cjs` · `GET /api/public-metrics`(로그인 없음 · 개인정보 없음). 정의는 **권장안 — 오너 확인 대기**.

## 1. 정의 (권장안)

| 지표 | 키 | 정의 |
|---|---|---|
| 기간 | `window` | **어제까지 30일**. 매일 00:05 KST 계산 · 그날 하루 고정(오늘은 하루가 안 끝나 뺀다) |
| 수업한 수강생 | `students` | 기간 안에 수업 기록이 있는 수강생 수 |
| 수업 | `lessons` | 한 번에 넣은 기록(같은 트레이너 · 날짜 · 입력 시각) = 1회. **그룹도 1회** |
| 1인 기준 수업 | `studentLessons` | 수강생마다 1회(그룹 4명 = 4) |
| 진행 판수 | `games` | 수업 행 판수 합 |
| 재결제 비율 | `repurchase` | 레슨 · 세트 결제(판수 있음 · 무효 제외) **2회 이상 수강생 / 결제 수강생** · **전 기간** · 환불 수강생 제외 · `ratePct` 는 내림 |
| 트레이너별 | `trainers[]` | 위와 같은 지표. 재결제 귀속 = 결제가 연결된 등록의 트레이너 · 연결 없으면 수강생 담당 |

- **빼는 것**: 합친 행(`students.merged_into`) · 테스트 계정(`#106` · 코드 상수) · 판수 조정 행(`adjreq:`) · 봇 `/판수정정` 행(양수 포함) · 0 이하 행.
  수업 판정은 원장 대시보드와 **같은 함수**(`ops-status.cjs` `isLessonRow`)다.
- **지휘탑 실측(9/30) 재현**: 31명 · 85회 · 566판 = 8/31~9/30(**오늘 포함 31일**) · 정정 행 포함 전 행 ·
  40/78 = 레슨 · 세트 결제 · 환불 수강생 2명 제외. 권장 정의로는 **31명 · 51회(1인 기준 81회) · 555판 · 40/78(51%)**
  (8/31~9/29 · 9/30 계산 기준).
- 트레이너별 재결제(9/30): 준구 16/37(43%) · 현태 23/48(47%) — 결제 16건(12명)이 등록에 연결되지 않아 담당으로 귀속했다.

## 2. API — `GET /api/public-metrics`

로그인 없음 · CORS 는 기존 허용 목록(mriacademy.gg) · `Cache-Control: public, max-age=300` · 분당 60회.

```jsonc
{
  "asOf": "2026-09-30T15:05:00.000Z",                 // 계산 시각
  "window": { "from": "2026-08-31", "to": "2026-09-29", "days": 30 },
  "students": 31, "lessons": 51, "studentLessons": 81, "games": 555,
  "repurchase": { "payers": 78, "repeaters": 40, "ratePct": 51, "basis": "all_time" },
  "trainers": [                                        // 활성 트레이너 + 원장 · 이름순
    { "name": "준구", "students": 8, "lessons": 14, "studentLessons": 19, "games": 131,
      "repurchase": { "payers": 37, "repeaters": 16, "ratePct": 43 } }
  ]
}
```

- **숫자 · 날짜 · 트레이너 표시명만** 싣는다. 허용 키 밖이 섞이면 서버가 응답 전에 막는다(`assertPublic`).
- `ratePct` 는 결제 수강생이 0 이면 `null`(0% 가 아니다 — 화면은 칸을 감춘다).
- 오늘 계산이 실패하면 **어제 저장본**을 내린다(`asOf` · `window` 로 날짜가 드러난다). 저장본도 없으면 503 `not_ready`.
- 저장: `ops_state` 키 `public_metrics` `{ date, value }` · 크론 `cron:publicMetrics`.
