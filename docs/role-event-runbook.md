# 역할군 이벤트 운영 순서 (18회 개설 · 17회 소급 추첨 · 2026-10-28)

> 설계 `docs/role-event-bot-design.md` · 재현 `docs/role-event-draw-verify.md`. 사람 이름 · 디스코드 id 는 여기에 적지 않는다(오너 DM · 채팅으로만).
> 명령은 전부 **오너 DM** 에서 친다. 시각은 KST `YYYY-MM-DD HH:mm`.

## 0. 배포 전 · 배포 직후

- 오너 손: Railway `mri-academy` env `ROLE_EVENT_ROLE_ID`(필수) · `ROLE_EVENT_ANNOUNCE_CHANNEL_ID` · `ROLE_EVENT_APPLY_CHANNEL_ID`(선택) · `PUBG_CURRENT_SEASON_NUM=43` 확인 · 「43s master」 역할 + 봇 역할을 그 위로.
- env 없이 배포해도 기동은 정상이다. §85 표가 있으니 기동 자기점검(`REQUIRED_SCHEMA`)도 통과한다. 그 상태에선 공지가 오너 DM 문안으로만 가고, 역할 부여 · 회수 버튼이 「ROLE_EVENT_ROLE_ID 가 없어서」로 막힌다. 신청 · 검증 · 추첨은 돈다.
- `PUBG_CURRENT_SEASON_NUM` 이 틀려도 시즌 id 는 목록 끝자리(`…-43`)로 먼저 찾는다(§12-⑬). 그래도 맞춰 두는 게 다른 기능(전적 · 성장)에 맞다.
- 슬래시 명령은 봇 재기동 때 등록된다. `/역할군`(글로벌)은 전파에 최대 1시간 걸린다.

## 1. 18회(43시즌) 개설

43시즌 종료일은 **아직 공식 발표 전**이다(10/28 확인 · 43.1 패치 노트에는 「시즌 종료 시 라이브 서버 점검과 함께 초기화」만 있다). 비공식 추정은 11/14 전후다.
규칙(지휘 G-4): **검증 시작 = 시즌 종료 다음 날 12:00 KST** · 마감 = 종료 전날 23:00 · 추첨 = 검증 시작 + 10일 저녁 21:00(결과 공지 + 10일 뒤라야 해서 저절로 늦춰질 수 있다).

| 경우 | 마감 | 검증시작 | 추첨 |
|---|---|---|---|
| **확정(오너 OK 10/28 「그 일정으로 열어」)** — 종료 11/14(토) 가정 · 공식 종료일이 나오면 검증 시각만 고친다 | `2026-11-13 23:00` | `2026-11-15 12:00` | `2026-11-25 21:00` |
| 종료 11/12(목) 공지 시 | `2026-11-11 23:00` | `2026-11-13 12:00` | `2026-11-23 21:00` |
| 종료 11/9(월) 공지 시 | `2026-11-08 23:00` | `2026-11-10 12:00` | `2026-11-20 21:00` |

- 늦은 쪽으로 여는 이유: 검증 시작이 실제 종료보다 **앞서면 시즌 중 값을 읽는다**(사고). 늦으면 며칠 늦게 검증할 뿐이다. 종료 공지가 나오면 `/역할군 일정` 으로 당긴다(검증 전까지 · 마감은 신청 중일 때만).
- 명령: `/역할군 회차생성 회차:18 시즌:43 마감:2026-11-13 23:00 검증시작:2026-11-15 12:00 추첨:2026-11-25 21:00`
- 공식 종료일 확정 시: `/역할군 일정 회차:18 검증시작:<종료 다음 날> 12:00` (검증 시각만 · 오너 지시 10/28)

## 2. 옛 방식(글 · 스샷)으로 이미 신청한 사람

다시 신청시키지 않는다. 회차를 연 뒤 오너가 대신 넣는다.

1. 스샷 · 글에서 **플랫폼 · 모드(TPP/FPP) · 인게임 닉**을 확인한다(모드가 안 보이면 그 사람의 경쟁전 기록이 있는 쪽 · 둘 다면 본인에게 한 번 묻는다).
2. `/역할군 수동등록 대상:<디스코드 id> 플랫폼:<카카오|스팀> 모드:<TPP|FPP> 계정:<인게임 닉>` — PUBG 조회 1번으로 계정 id 를 확정하고 `review_note='수동등록'` 이 남는다.
3. 본인에게 따로 알리지 않는다(사람에게 나가는 글은 오너 손). 결과 공지에 멘션으로 보인다.
4. 마감 전이면 본인이 나중에 `/역할군신청` 을 해도 같은 줄이 갱신될 뿐이다(1인 1신청).

## 3. 17회(42시즌) 밀린 추첨 — 기프티콘 3매 (9/21 약속)

역할은 9/27 수동으로 끝났다. 이번엔 **추첨만** 한다. 운영 DB 에 쓰기 전에 아래 1 ~ 2 를 드라이런한다.

1. **후보 모으기(읽기만)** — `/역할군 채널읽기 채널:<#역할군신청 id> 시작:<42시즌 신청 시작> 끝:<17회 마감>` → 오너 DM 으로 글 목록(시각 · 디스코드 id · 글 · 첨부 수). 세션이 이걸로 후보 표(#번호 · 플랫폼 · 모드 · 닉)를 만들어 오너 확인을 받는다.
2. **드라이런** — 그 표를 메모리 가짜 세계(`scripts/role-event-dryrun.cjs` 방식)에 넣어 소급 회차 → 수동등록 → 검증 → 3명 추첨 흐름을 먼저 돌린다(42시즌 RP 는 실 PUBG 를 1인 1콜로 읽는다 · DB 쓰기 0).
3. **소급 회차 생성** — `/역할군 회차생성 회차:17 시즌:42 마감:<17회 원래 마감> 검증시작:<오늘 + 2시간쯤> 추첨:<공지 + 24시간 뒤 저녁> 소급:true 당첨수:3`. seed 약속값이 공지된다(채널 미설정이면 오너 DM 문안).
4. **수동등록** — 후보 표대로 `/역할군 수동등록 회차:17 …` (검증 시작 전까지).
5. 검증 시작 시각에 크론이 42시즌 최종 RP 를 1인 1콜로 읽는다 → 오너 카드 → [결과 공지](소급은 유예 24시간 · 역할 버튼은 막혀 있다).
6. 추첨일 → 참여자 확정 공지(hash) → 1시간 뒤 drand 라운드 → 3명 추첨 · 발표 · 당첨 DM(48시간 · 미연락 승계).
7. 기프티콘 구매 · 발송은 오너 손 → 카드 [지급함].

17회와 18회를 동시에 열어도 된다(회차 번호로 나뉜다). 단 `/역할군신청` 은 열린 회차(18회)로만 간다 — 17회는 수동등록만 받는다.
