## 0. 이 기준이 바꾸는 것

- **색감 · 글꼴은 합격한 쇼츠 그대로** 쓴다(베이지 브리핑룸 · Black Han Sans · Anton · Special Elite · IBM Plex Sans KR).
- **영상용 장식은 뺀다**: 도장, 포스트잇, 테두리 딱지, 기울인 카드, 테이프, 핀.
- **진행 순서**: 진단표 → 회색 뼈대 → 오너 구조 판정 → 색과 문구 입히기. 뼈대 판정 전에는 운영 화면을 바꾸지 않는다.

## 1. 위계

- **주인공은 하나**이고 확실히 크게 둔다. 숫자는 크게, 단위는 작게 쓴다(`45,000` 크게 · `원` · `10판` 작게).
- **강조색은 뜻이 있는 한 곳에만** 쓴다. 가격 숫자와 신청 버튼이 그 자리다.
- **채운 버튼은 구획당 하나**다. 나머지 행동은 글자 링크로 둔다.
- **종류가 셋을 넘으면** 색 딱지 대신 회색 글씨로 나눈다.

## 2. 틀

- 박스와 테두리를 벗기고 **굵기 · 농도 · 여백**으로 나눈다.
- 훑어보는 목록에는 **줄마다 박스를 씌우지 않는다**.
- **틀 안에 틀을 넣지 않는다**. 겹침은 한 겹까지다.
- 탭이나 분류는 **한 틀로 묶는다**.

## 3. 정렬

- 로고부터 바닥글까지 **왼쪽 시작선은 하나**다.
- 같은 종류는 **같은 틀 · 같은 높이**로 맞춘다.
- 여러 개를 훑어보는 글은 **왼쪽 정렬**한다.
- 칸 수는 **서로 나눠떨어지게** 고른다(3과 6).

## 4. 묶음과 순서

- 카드 안 순서는 **사진 → 제목 → 부가정보 → 행동**이다.
- 사진 위에는 **큰 글씨 하나까지만** 얹는다. 문장은 사진 아래 단색 바탕에 쓴다.
- 주인공이 하나면 크게 하나로 둔다. 여럿이면 **같은 크기로 나란히** 둔다.
- 폰에서 가로로 넘기는 목록은 **끝을 잘라** 다음 것이 있다는 걸 보여 준다.

## 5. 아이콘과 글자

- **글자가 기본**이다.
- 아이콘을 쓴다면 같은 굵기의 선, 한 색, 한 벌로 맞춘다.
- **메뉴와 제목에 이모지를 쓰지 않는다**.
- 맨 위 메뉴는 **한 줄, 글자만** 쓴다.

## 6. 점검 숫자 (진단표와 같은 칸)

| 항목 | 목표 |
|---|---|
| 구획의 주인공이 제일 크게 보이는가 | 예 |
| 강조색이 쓰인 요소 수 | 2 이하 |
| 채운 버튼 수 | 1 |
| 왼쪽 시작선 수 | 1 |
| 틀이 겹친 깊이 | 1겹 |
| 색 딱지 종류 수 | 0 (셋이 넘으면 회색 글씨) |
| 제목 · 메뉴 이모지 | 0 |
| 사진 위 문장 | 0 (큰 글씨 하나까지) |
| 가로로 밀리는 곳 | 폰 가로 넘기기 말고 0 |
